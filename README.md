# sistema-de-aprova-o-de-requisi-es
Sistema web de gestão de aprovações corporativas. Centraliza requisições internas, como contratação, movimentação de cargos e salários e desligamento, e as encaminha por fluxos multinível configuráveis por área, com aprovação sequencial. Mostra em que etapa cada pedido está, guarda o histórico de decisões e avisa solicitantes.
